# NAME
bininfo - outputs information from binary ELF64 files as JSON

# SYNOPSIS
**bininfo** [*FILE*]  

# DESCRIPTION
Outputs information from binary ELF64 files to stdout as JSON

# EXAMPLES
**bininfo** /usr/bin/ls
